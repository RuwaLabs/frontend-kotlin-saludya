# frontend-kotlin-saludya
The Kotlin frontend of SaludYa, designed for patients.

Inicio de sesión del paciente: [US-04](docs/iam-us04.md).

Solicitud de recuperación de contraseña: [US-23](docs/iam-us23.md).
