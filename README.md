# frontend-kotlin-saludya
The Kotlin frontend of SaludYa, designed for patients.

## IAM

Verificación de identidad del paciente por DNI: [US-01](docs/iam-us01.md).

Registro de correo, contraseña y celular: [US-02](docs/iam-us02.md).

Verificación de correo y creación de cuenta: [US-03](docs/iam-us03.md).

Inicio de sesión del paciente: [US-04](docs/iam-us04.md).

Solicitud de recuperación de contraseña: [US-23](docs/iam-us23.md).

Restablecimiento de contraseña: [US-24](docs/iam-us24.md).

Ayuda por pérdida de acceso: [US-25](docs/iam-us25.md).

Cierre de sesión con confirmación: [US-28](docs/iam-us28.md).

Aviso de sesión expirada: [US-29](docs/iam-us29.md).
